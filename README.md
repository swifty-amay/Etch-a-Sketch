# Etch-a-Sketch
A browser version of something between a sketchpad and an Etch-A-Sketch.

## Summary
Etch-a-Sketch allows you to create the pictures using square grids and the mouse pointer as your paint brush. Each time you hover over a grid using pointer, the grid gets painted and to unselect any grid just click on it, it will get deselected. You also have a **New Grid** button through which you can select the number of grids to show. After you have completed you can take a screenshot of your work and can share it with your friends...🙂

## Technologies Used
The webpage is completely built using **HTML, CSS and Javascript**.
- HTML is used to lay out the basic page structure.
- CSS is used for styling.
- Javascript is used for the following purpose:-
    - DOM Manipulation - for dynamically embedding the html elemets into the DOM tree.
    - Event Listeners - to add functionality to a button when it is pressed.
    - Event Listerner for different <u>Mouse Gestures</u> - like change the color as the mouse pointer enters a square grid, change the grid back to its original color when the user performs a click on a grid.
